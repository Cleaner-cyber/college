# 📚 1002 中国大学的专业规划 - 分类索引

> **【浪尖大学四年知识库 · 专业规划索引】**
> **说明：** 本索引汇总「1002中国大学的专业规划」文件夹下所有专业分类的内容导航
> **更新：** 2026年6月新增014交叉学科门类，首批15个专业

---

## 📖 内容概览

本分类按照中国大学 **14个学科大类** 进行组织，涵盖从哲学到交叉学科的所有专业门类，提供各专业的发展规划指导。

**学科分类体系：**
- [[01哲学类]] - 哲学、逻辑学、宗教学、伦理学
- [[02经济学类]] - 经济学、金融学、财政学等
- [[03法学类]] - 法学、政治学、社会学等
- [[04教育学类]] - 教育学、体育学等
- [[05文学类]] - 中国语言文学、外国语言文学、新闻传播学等
- [[06历史学类]] - 历史学、考古学等
- [[07理学类]] - 数学、物理、化学、生物等基础科学
- [[08工学类]] - 计算机、机械、土木、电子等工程技术（最大类目）
- [[09农学类]] - 农学、林学、畜牧兽医等
- [[010医学类]] - 临床医学、口腔医学、护理学等（10个二级类）
- [[011管理学类]] - 工商管理、公共管理、会计学等
- [[012艺术类]] - 美术学、音乐与舞蹈学、戏剧与影视学等
- [[013军事学类]] - 军事学专业（不公开招生，目录暂存）
- [[014交叉学科]] - 具身智能、脑机科学与技术等（2026年新增门类）

## 🗺️ 专业选择决策树

```
你是文科生还是理科生？
│
├─ 文科生
│   ├─ 对商业感兴趣 → 经济学类/管理学类
│   ├─ 对法律感兴趣 → 法学类
│   ├─ 对教育感兴趣 → 教育学类
│   ├─ 对文学感兴趣 → 文学类
│   ├─ 对历史哲学感兴趣 → 哲学类/历史学类
│   └─ 对艺术感兴趣 → 艺术类
│
└─ 理科生
    ├─ 对计算机感兴趣 → 工学类(计算机)
    ├─ 对医学感兴趣 → 医学类
    ├─ 对基础科学感兴趣 → 理学类
    ├─ 对工程感兴趣 → 工学类(机械/土木/电气等)
    ├─ 对农业感兴趣 → 农学类
    └─ 对管理感兴趣 → 管理学类
```
