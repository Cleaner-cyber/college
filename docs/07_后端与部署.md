# 07 · 后端（Supabase）与部署

> v1.0 · 写给项目负责人：从零把线上环境跑起来的完整步骤。前端架构见 docs/05。

## 1. 架构一句话

前端是纯静态站；"后端"由 Supabase 承担：**Auth**（邮箱+密码）+ **Postgres**（云存档，RLS 行级权限保证只能读写自己的数据）。前端用 anon key 直连，安全性由 RLS 兜底——anon key 是公开的，可以放进前端。

## 2. 创建 Supabase 项目（约 5 分钟）

1. 打开 https://supabase.com → 注册/登录 → **New project**
   - Region 选 Singapore（国内访问相对最快）
   - 数据库密码自己记好（本项目用不到直连，但要保存）
2. 建表：Dashboard → **SQL Editor** → New query → 把仓库里 `supabase/schema.sql` 整段粘贴 → **Run**
   - 会创建 `game_saves` 表 + RLS 策略 + 索引，重复执行也安全（幂等）
3. 认证设置：Dashboard → **Authentication → Sign In / Up**
   - 确认 Email 打开
   - **内测期建议关掉 "Confirm email"**（否则每个用户要先去邮箱点确认链接才能登录）；正式期再打开
4. 拿密钥：Dashboard → **Settings → API**
   - `Project URL` → `VITE_SUPABASE_URL`
   - `anon public` key → `VITE_SUPABASE_ANON_KEY`

## 3. 本地联调

```bash
cp .env.example .env        # 填入上面两个值
npm run dev                 # 打开的是登录页 → 注册 → 正常游戏，存档在云端
```

不配置 `.env` 时应用自动进入**本地试玩模式**（无登录，存档在浏览器 localStorage）——开发关卡内容时用它最方便。

## 4. 部署

### 方案 A：Vercel（推荐，免费额度足够内测）
1. Vercel 导入 GitHub 仓库，框架选 Vite（自动识别）
2. Environment Variables 里加 `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY`
3. Deploy。完成后每次 push 自动重新部署

### 方案 B：任何静态托管（GitHub Pages / 对象存储 + CDN…）
1. 本地 `.env` 配好后 `npm run build`
2. 把 `dist/` 整个目录传上去即可（环境变量在**构建期**注入，产物里已带）

路由说明：当前用 HashRouter（URL 形如 `/#/home`），任何静态托管零配置。若在 Vercel 上想要干净 URL，把 `src/main.tsx` 里 HashRouter 换成 BrowserRouter，并在项目根加 `vercel.json`：
```json
{ "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }] }
```

## 5. 数据与运营

- 每个用户一行 `game_saves`，`state` 是完整 PlayerState（结构见 docs/02）
- `semester` 是生成列，直接可做漏斗：`select semester, count(*) from game_saves group by 1;`
  （prologue=卡在序章 / y1s1=游玩中 / y1s1-end=通关）
- 将来做"相对分布/稀有度"（docs/01 判定机制）：所有玩家四轴都在 `state->'axes'` 里，管道已留好
- 删号：Supabase Dashboard → Authentication → 删除用户，存档随 `on delete cascade` 自动清掉

## 7. 常见问题

| 现象 | 原因/处理 |
|---|---|
| 登录报"出了点问题" | 多为网络/URL 配错；打开浏览器控制台看具体报错 |
| 注册后提示去邮箱确认 | Confirm email 开着；内测期建议关掉（见 §2.3） |
| 换电脑进度没了 | 确认登录了同一账号；本地试玩模式的进度不上云 |
| 想清某个玩家进度 | SQL Editor：`delete from game_saves where user_id = '...';` |
