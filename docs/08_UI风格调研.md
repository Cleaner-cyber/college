# 08 · 年轻人产品 UI 风格调研

> v1.0 · 2026-07 · 为《大学模拟器》整体 UI 优化做的市场调研与设计决策。
> 结论先行：**保留现有「温暖纸感」底盘，叠加「轻游戏化 + 弥散渐变氛围 + 微交互」三层年轻化改造**，不整体换风格。

---

## 1. 调研范围与方法

- 2025–2026 国际 UI 趋势报告（Midrocket、Lucky Graphics、UX Pilot、Tenet、BairesDev 等）
- 国内年轻人高频产品拆解：多邻国（游戏化标杆）、小红书（内容卡片流）、恋与深空（情感化视觉小说）
- 极简高级感标杆：Notion / Linear / Arc Browser
- 本产品受众：**准大一新生（17–19 岁）**，桌面端网页，使用场景是「认真地玩一个有用的游戏」

## 2. 趋势速览（与本产品相关的部分）

### 2.1 国际趋势 2025–2026

| 趋势 | 内容 | 对本产品的适用性 |
|---|---|---|
| **Bento Grid 布局** | 便当盒式分块卡片，信息密度高但秩序感强 | ★★★ Home 三栏已是雏形，强化卡片的分块感即可 |
| **多巴胺配色（Dopamine UI）** | 高饱和点缀色制造愉悦感，但 2026 年趋势是「克制的多巴胺」——大面积中性 + 小面积高能量色 | ★★★ 与我们「单色系 + 一个强调色」铁律完全兼容 |
| **情感化微交互** | 按钮按下的弹性、数值跳动、完成时的小动效，给用户「小奖励」 | ★★★ 游戏产品必备，当前偏静态 |
| **弥散渐变 / Aurora 背景** | 大面积柔和的径向渐变光斑做氛围层，替代纯色背景 | ★★☆ 低饱和暖色光斑可用，禁用赛博朋克渐变（铁律） |
| **轻玻璃拟态** | 半透明 + 背景模糊，用在浮层/顶栏 | ★★☆ 顶栏、VN 对话盒、弹窗适用 |
| **暗色模式优先** | 移动端 80%+ 用户偏好暗色 | ★☆☆ 本产品是「信纸/档案」隐喻的桌面端，浅色纸感是身份，不做暗色 |
| **Y2K / 新怀旧** | Z 世代复古像素、贴纸感 | ★☆☆ 与「档案/信纸」气质冲突，仅借鉴「贴纸式徽章」一点 |

### 2.2 多邻国（游戏化标杆）

从国内设计社区对多邻国的拆解（优设、人人都是产品经理、数英）提炼：

1. **目标拆小 + 进度外显**：进度条、连胜、宝箱，任何时刻都能看到「我走到哪了」。→ 对应我们的四年时间轴、主线序号、行动点，要做得更「看得见摸得着」。
2. **卡通 UI、无冗余文字**：状态尽量图形化（红心、宝石、进度环），文字降级为辅助。→ 行动点从「3/3」文字升级为发光圆点；能力徽章做成「拿到了东西」的实体感。
3. **实时正反馈动画**：答对即时弹跳/撒花。→ 我们在速结行动结果、能力解锁、结算数值动画上补微交互。
4. **IP 角色贯穿**：吉祥物是记忆点。→ 「学长」立绘与头像已是 IP 位，界面里让他出现得更有存在感（气泡、角标）。

### 2.3 小红书（内容卡片流）

- 双列瀑布流 + 大圆角卡片 + 图片优先，文字压到两行以内；
- 卡片 hover/点按有轻微抬升，边界靠投影而非重描边。
- → 文件夹「作品集」横向大图卡已对齐该气质，进一步统一投影与圆角语言。

### 2.4 恋与深空 / 视觉小说（情感化演出）

- 情绪靠光影与色温传达，UI 面板极度收敛，不抢立绘；
- 对话盒半透明 + 模糊，名牌是强调色小块。
- → VN 模式对话盒加玻璃感与底部渐变压暗，让立绘/场景更突出。

### 2.5 Notion / Linear / Arc（极简高级感）

- Notion：暖色极简、衬线标题、柔和表面（warm minimalism, soft surfaces）；
- Linear：低透明度、软边缘、模块化组件的克制交互模型；
- Arc：为在意审美的人设计，秩序感（垂直空间）+ 个性化。
- → 证明「克制」本身就是年轻人认可的高级感。我们的纸感底盘不需要推翻，需要的是**手感**（投影层次、微交互、氛围光）。

## 3. 设计决策：温暖纸感 × 轻游戏化

**一句话**：底子还是「文件夹/档案/信纸」，但摸起来要像 2026 年的产品——有光、有弹性、有奖励感。

### 3.1 不变（身份层）

- 纸色底 `#F7F5F0` + 墨色 `#1C1B18` + 赤陶强调色 `#C05A32`，单强调色铁律不破；
- 无暗色模式、无赛博渐变、无花哨转场；
- 信息结构（Home 三栏 / VN 演出 / 拟真对话）不动。

### 3.2 升级（体验层）

| 层 | 改造 | 落点 |
|---|---|---|
| **氛围** | 弥散渐变：纸面上叠 2–3 个超低饱和暖色光斑（固定、不动画），保留点状纸纹 | `index.css` body 背景 |
| **层次** | 投影体系化：`shadow-soft`（静置卡）/ `shadow-lift`(hover) / `shadow-pop`（弹窗），弱化描边依赖 | tailwind tokens + Panel/卡片 |
| **玻璃** | 顶栏、VN 对话盒、弹窗遮罩用半透明 + backdrop-blur | HomePage header / ScreenPlayer / 弹窗 |
| **微交互** | 按钮 hover 抬升 + active 回弹；卡片 hover 抬升统一 -translate-y；数值 pop；能力徽章「叮」一下出现 | Button / 各卡片 / 既有 num-pop 扩展 |
| **游戏化外显** | 行动点=发光圆点（可用时呼吸微光）；主线当前关卡加强调色描边+序号徽章渐变；时间轴加纵向连线（走过的实线/未来虚线）；能力徽章立体化 | HomePage / StatusRail / NavColumn |
| **多巴胺（克制版）** | 强调色只在「可交互/进行中/奖励」出现；空态和已完成一律退灰。新增 `accent-deep` 做 hover 深化，不新增第二色相 | tokens |
| **VN 演出** | 对话盒玻璃化 + 场景底部渐变压暗托底；名牌圆角化；选项按钮玻璃卡 | ScreenPlayer |
| **拟真对话** | 聊天窗口标题栏做成「应用感」（三个窗口圆点）；AI 气泡白底+软投影与用户墨色气泡拉开对比 | ChatScript |

### 3.3 明确不做

- 不引入第二强调色相（多巴胺趋势的「多色」版本与铁律冲突）；
- 不做背景动画光斑（分散注意力，且违反「克制」）；
- 不做 Y2K/像素风（与档案隐喻冲突）；
- 不改任何交互流程与文案（本次纯视觉层）。

## 4. 组件级改造清单（实施对照）

1. `tailwind.config.js`：新增 `accent-deep`、`shadow-soft/lift/pop`、`glow` 呼吸动画、`pop-in` 弹入动画；
2. `src/index.css`：弥散光斑背景、focus-visible 焦点环、滚动条微调；
3. `Button`：primary 加软投影 + hover 抬升，secondary hover 边界深化；
4. `Panel`：`shadow-soft`、描边减淡；
5. `HomePage`：顶栏 sticky+玻璃；导航 pill 化；时间轴连线；行动点发光；主线当前卡强化；速结卡、结算条、弹窗统一新投影语言；
6. `LoginPage`：标题字重层次 + 卡片投影 + 输入框焦点环;
7. `ScreenPlayer`（VN）：对话盒玻璃化、名牌圆角、底部渐变托底、选项卡玻璃化；
8. `ChatScript`：窗口标题栏应用化、气泡对比强化（**保持既有类名锚点：`h-[560px]`、`bg-accent-soft`、`mb-2.5`、`rounded-tl-md`、`w-full` 等自动化测试依赖不变**）；
9. `Tour`：气泡投影/圆点进度微调。
