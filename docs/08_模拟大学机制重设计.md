# 08 · 模拟大学机制重设计（调研 + 方案）

> v0.2 · 2026-07 · 状态：**已确认；P0 已实现**（事件引擎/入学特质抽卡/标签系统/历史最高值/y1s1 试点事件 12 张）。P1-P3 待做。
> 背景：产品第一部分（AI 教学主线）已完整；第二部分"模拟大学"现状过于简陋——每学期 3 行动点买 4 个静态选项，文字反馈+固定加值，数值面板几乎不被游戏读取。目标是重做为"肉鸽感 / 不同选择导向不同人生"的模拟层。
> 本文档 Part A 为多源交叉核验的调研结论（102 代理深度调研，逐条 3 票对抗验证）；Part B-E 为据此给出的机制方案。

---

## Part A · 同类游戏机制调研结论（已核验）

### A1. 《人生重开模拟器》(lifeRestart, 开源 MIT, ~10.4k stars) —— "轻量人生 run" 的完整参考实现
**置信度：高（全部经开源主源码逐字验证）**

1. **事件引擎是三层结构**：每年从按年龄配置的事件池取 `[eventId, weight]` 对 → 条件过滤（`exclude` 命中则不触发、`include` 必须命中才触发）→ 剩余事件加权随机（weightRandom）。
2. **多段剧情用扁平数据实现**：事件可带 `branch` 数组（`[条件表达式, 下一事件ID]`），运行时取第一个命中分支跳转 next 事件——不需要写剧情树代码，链全在数据表里。
3. **run 起点即 build**：开局系统随机放出 10 个天赋抽 3 个，再在颜值/智力/体质/家境四轴间自由分配 20 点。天赋是具体规则："迟来之财"90 岁家境+4、"老司机"保证不发生车祸事件、"天命"初始点+8——天赋直接钩进事件条件系统。
4. **结算公式明确**：为每轴记录**历史最高值**，总评 `SUM = floor(五轴历史最高值之和 × 2 + 最高年龄 / 2)`；SUM 与各轴分别做**阈值分档评语**，构成可刷屏的"人生总结报告"。
5. **内容与代码彻底分离**：全部内容在 5 张 Excel 表（成就/年龄事件池/角色/事件/天赋），构建时转 JSON——与本项目铁律 1 同构，数据表设计可直接抄。
6. **传播事实**（置信度中，开发者自报口径）：两人半月做完，2021-09-03 上线，3 天约 2 亿访问、数百万玩家；传播载体正是可截图的逐岁事件流与结算总结页。
7. **已证伪，勿引用**："事件池 1500+ 个"的流传说法 0-3 票被否。

### A2. 《Reigns》—— "极简二选一也能让玩家觉得是自己写的剧本"
**置信度：高（设计师 François Alliot 一手 postmortem）**

1. **核心循环**：左右滑二选一 + 恰好四资源（教会/民众/军队/金钱），任一资源**满格或清零都死**，死后下任君主重开——资源不是越高越好，是走钢丝。
2. **动态加权卡袋**：每次滑动后按全局状态**重编卡袋**。权重用卡牌 `size` 实现：战争激活时约 10 张战争卡被赋大 size 挤占卡袋、压低闲杂卡概率；战争结束整组移出。卡袋可收缩到单张卡形成线性剧情（魔鬼跨代长线）。
3. **关键设计结论**：叙事按递进层次编写（一次性卡 → 短期迷你剧情线 → 长线弧）。**即使只有少数卡以先前选择为条件，玩家也会把整个大部分随机的游戏感知为"响应我选择的"**，并自行脑补因果——这是低成本制造"我的选择导致了这个结局"的关键原则。

### A3. 《Long Live the Queen》—— 日程排期养成的数值范本
**置信度：中高（社区逆向数据仓库，多方一致）**

1. **训练收益受状态调制**：每周选课，技能增益 `= 5 × max(0, 2 + 心情修正 + 微量累积加成)`——心情不匹配可把训练**归零**，匹配则加速；心情是有界向量（各轴 [-5,5]，向量加法+钳制）。
2. **双段阈值把数值绑成 build**：技能封顶 50，同子组两个兄弟技能均达 25 后上限才升到 100；子组三技能全达 25 解锁"套装"，穿戴时该子组全部 +10——对专精的显式奖励。
3. **run 结构与多结局**：固定 40 周日程；结局分死亡/通用/邪恶等类型 + 编号后日谈；判定除可见技能外还有**隐藏数值**（残忍值、平民/贵族好感 -100~100：贵族好感 ≤-40 第 29 周内战、平民好感 ≤-45 第 39 周革命）。

### A4. 调研缺口（诚实声明）
《中国式家长》（悟性/班干部竞选/相亲）、BitLife、美少女梦工厂、火山的女儿、Growing Up 的具体规则没有 claim 通过核验，本报告不基于它们下结论；多周目元进度（跨局继承）的具体规则也未被验证覆盖。方案中涉及这两块的部分标注为"设计推导"而非"调研结论"。

## Part B · 现状差距诊断

| 参照系统 | 同类游戏做法 | 我们现状 |
|---|---|---|
| run 起点 build | 10 抽 3 天赋 + 20 点自由分配 | 无（人人开局相同） |
| 事件系统 | 条件过滤+加权随机+branch 链 | 4 个静态选项，无随机无链 |
| 选择反馈 | 卡袋被选择重编，玩家感知"游戏在回应我" | 选择只加数值，无回应 |
| 数值被读取 | 门槛解锁选项/事件、检定、双段上限 | 数值只在结算页看一眼 |
| 资源压力 | 四资源满/空都死；精力/心情调制收益 | 精力只是一条不疼不痒的槽 |
| 结算报告 | 历史最高值公式+阈值评语，可截图刷屏 | 数值条+一句判词 |
| 多结局 | 类型化结局 + 编号后日谈 + 隐藏数值参与判定 | 最高轴 7 选 1；flag 零机制作用 |
| 元进度 | 天赋/成就跨局解锁 | 无重开动力 |

## Part C · 机制方案（8 个系统）

### C1. 入学人设卡（build 起点）｜参照 lifeRestart 天赋 10 抽 3
序章新增一步：随机亮出 **8 张「入学特质」抽 2**。特质三种效果类型（与事件系统钩连）：
- 轴修正：`小镇做题家` 学术+2 现金-1；`家境宽裕` 现金+2、兼职类事件权重减半
- 事件权重：`社恐` 社交事件权重 ×0.5 但成功后奖励 ×2；`夜猫子` 解锁深夜事件组
- 规则改写：`钝感力` 精力下限事件不触发；`卷王体质` 学术类行动点花费 -1（每学期一次）
特质在属性面板常驻可见，是玩家的"这一世人设"。**重开动力的种子。**

### C2. 学期事件流（核心改造）｜参照 lifeRestart 三层引擎 + Reigns 二选一
行动点的消耗对象从"4 个静态选项"改为"**过日子**"：花 1 点 → 从本学期事件池按 lifeRestart 三层结构抽 1 张事件卡（条件过滤 → 加权随机）。事件卡呈现为 Reigns 式 **2~3 选一**：
```jsonc
// /content/events/y1s1.json（内容代码分离，同 lifeRestart Excel→JSON）
{
  "id": "roommate-conflict",
  "weight": 10,
  "include": "",                    // 条件表达式：轴值/特质/标签/已历事件
  "exclude": "tag:独行侠",
  "text": "室友半夜开黑到两点，你明天有早八。",
  "options": [
    { "label": "戴上耳塞忍了", "deltas": { "energy": -1 }, "tags": ["老好人+1"] },
    { "label": "开口谈规则", "check": { "axis": "expression", "dc": 3 },
      "success": { "text": "…谈成了轮值安静日", "deltas": { "expression": 1 }, "tags": ["敢开口+1"] },
      "fail":    { "text": "…气氛僵了一周", "deltas": { "energy": -1 }, "tags": ["独行侠+1"] } },
    { "label": "搬去图书馆住", "deltas": { "academic": 1, "energy": -2 }, "next": "library-regular" }
  ]
}
```
- `check`：轴值检定（LLtQ 式），成功率 = f(轴值 vs dc)，**成败都有戏**——数值第一次真正被读取
- `next`/branch：跨学期连锁线（室友线/恋爱线/家人线/社团线/导师线/创业线），一条线 3-5 张卡跨多学期
- 原 4 个速结行动保留为每学期固定可选的"计划行动"（保底确定性），与随机事件并存：**计划 vs 冒险**的取舍

### C3. 标签系统（人设演化）｜参照 Reigns 卡袋重编
选择累积**标签计数**（老好人/敢开口/卷王/夜猫子/恋爱脑/独行侠…）。标签达到阈值（如 3 次）后：
- 显式"觉醒"弹卡：「你正在成为：敢开口的人」（可见反馈）
- 重编事件卡袋：相关事件权重 ×2 / 互斥事件移出（Reigns size 挤占）
- 进结局判定与人生总结
按 A2.3 结论：**只需少量条件卡**（每学期 2-3 张标签门控卡）就能让玩家感知"游戏在回应我"。

### C4. 精力=硬资源｜参照 Reigns 资源走钢丝
- 精力 ≤1：强制触发低精力事件（生病/早八睡过/情绪崩），本学期一张
- 精力满：解锁部分事件的"高精力选项"（多一个更好的分支）
- "什么都不做"升格为策略而非安慰剂

### C5. 开局 flag 入机制（现有资产盘活）
序章立的 flag（年薪/城市/工作类型/下班时间）从"结局对照展示"升级为：
- 每学年一次「校招季传闻」事件按 flag 定向出题（想去大厂 → 实习卷不卷的取舍卡）
- 结局判定维度之一：flag 达成度（见 C7）

### C6. 结算报告升级（可截图的人生总结）｜参照 lifeRestart 结算公式
- 记录**各轴历史最高值**（不只当前值）；总评 `SUM = 2×Σ(历史最高) + 修正`，阈值分档判词（lifeRestart 同款结构）
- 毕业页改为**一张可截图长卡**：四年时间线（关键事件+标签觉醒节点）→ 标签画像 → flag 对照（立的 vs 活成的）→ 身份卡 → "你自己做了 N/M 件" → 差一点彩蛋（见 C7）
- 学期结算加入"本学期最戏剧性一刻"回放（从事件史挑 check 成败卡）

### C7. 多结局扩容 + "差一点"提示
结局判定 = **标签画像 × 四轴形状 × flag 达成度 × 关键链完成度**，身份卡从 7 种扩到 **20±**（好坏皆有，坏结局指向选择不指向出身，沿用产品定义红线）。
结算页底部一行："**差一点**：如果大二那年你把「敢开口」攒到 5，你会看到另一张身份卡。"——lifeRestart 式重开钩子，明示"选择→结局"因果（A2.3 原则的显式版）。

### C8. 多周目元进度（轻量）｜设计推导（调研未覆盖，规模从小做起）
- 毕业解锁 1-2 张新特质进下局抽卡池（按本局结局类型定向解锁）
- 「学长的信」：新 run 序章出现上一世自己的一句话（从上局结算摘要生成）
- 不做数值继承（避免破坏 run 平衡），只做内容解锁

## Part E · 契约变更清单（铁律 3：需确认后才动 /src/contracts）
- `PlayerState` 新增：`traits: string[]`（入学特质）、`tags: Record<string, number>`（标签计数）、`axesPeak: Axes`（历史最高值）、`eventHistory: string[]`（已历事件 id，供 include/exclude/结局判定）
- 新类型：`SimEvent`（事件卡）、`Trait`（特质）——放 contracts 新文件，不动现有类型
- `LevelResult` 不变；事件系统走独立的 `runEvent` action，不经过关卡插件接口
