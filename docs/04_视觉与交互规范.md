# 04 · 视觉与交互规范

> v2.1 · 补充文档，与 CLAUDE.md「视觉基调」一致。改样式前先读本文；令牌值落在 `tailwind.config.js`。
> v2 变更：桌面端优先（1280px 基准）；新增 Home 主界面布局网格与 Panel 组件规范。
> v2.1 变更（依据 docs/08 调研）：「温暖纸感 × 轻游戏化」——新增弥散光斑氛围层、投影体系（soft/lift/pop/glow）、玻璃顶栏与 VN 对话盒、行动点呼吸微光、弹窗 pop-in 动效。

## 1. 基调

极简、克制、留白多。参考气质：**文件夹 / 档案 / 信纸**。
禁止：赛博朋克渐变、霓虹色、花哨动效、拟物阴影堆叠。

## 2. 色彩令牌（tailwind.config.js → theme.extend.colors）

| 令牌 | 值 | 用途 |
|---|---|---|
| `paper` | `#F7F5F0` | 页面底色（信纸米白） |
| `card` | `#FFFFFF` | 卡片/输入框底色 |
| `ink` | `#1C1B18` | 正文、主按钮底 |
| `ink-soft` | `#6B675E` | 次要文字、标签 |
| `line` | `#E4E0D6` | 分隔线、边框、未完成状态 |
| `accent` | `#C05A32` | **唯一强调色**（赤陶色）：行动点、学长标签、验收进度、判词 |
| `accent-deep` | `#A84A27` | accent 的 hover 深化档（不算新色相） |
| `accent-soft` | `#F3E4DC` | 强调色的浅底（标签底、选中态） |

规则：一个界面里 accent 出现面积 ≤ 10%。新增颜色需先在本表登记。

### 2.1 氛围与投影（v2.1 新增）

- **弥散光斑背景**：`index.css` 里 body 叠 3 个超低饱和暖色径向光斑（opacity ≤ 0.07，固定不动画）+ 原点状纸纹，`background-attachment: fixed`。
- **投影体系**（tailwind `boxShadow`，卡片层次靠投影不靠重描边）：
  | 令牌 | 用途 |
  |---|---|
  | `shadow-soft` | 静置卡片（Panel、速结卡、气泡） |
  | `shadow-lift` | hover 抬升态（配 `hover:-translate-y-0.5`） |
  | `shadow-pop` | 弹窗 / VN 对话盒 |
  | `shadow-glow` | 强调色微光（当前主线序号、行动点、激活文件卡、输入框 focus） |
- **玻璃拟态**：只用于顶栏（`bg-paper/80 backdrop-blur-md`）、VN 对话盒/选项（`bg-paper/90 backdrop-blur-md`）、登录卡。内容卡不做玻璃。

## 3. 字体与排版

- 字体栈：系统中文黑体（PingFang SC / Microsoft YaHei），不引入 webfont。
- 字号：正文 17px（对话/台词）、次要 14~15px、标签 11~12px + `tracking-widest`。
- 台词多行：JSON 文案里用 `\n` 分段，组件统一 `whitespace-pre-wrap`。
- 版心：
  - Home 主界面：`max-w-[1200px]` 居中，三栏网格 `200px | 1fr | 280px`，栏距 24px
  - 关卡页/结算页：叙事内容窄栏 `max-w-xl`（576px）居中——读台词的最舒适行宽
  - 登录页：单卡片 `max-w-sm` 居中

## 4. 组件规范（/src/components/ui）

| 组件 | 规范 |
|---|---|
| `Button` | 三档：primary（ink 底白字）/ secondary（白底描边）/ ghost（下划线文字）。圆角 `rounded-xl`，按压 `active:scale-[0.98]` |
| `Typewriter` | 38ms/字；**点击正文即跳过**（必须保留，防止玩家等烦）；未完成时下一步按钮隐形占位（opacity-0），避免布局跳动 |
| `FakeLoading` | 进度条 + 学长旁批轮播。demo 所有「AI 生成」都是这个演出；时长由内容 JSON 的 `effects.fakeLoading.ms` 决定，代码不写死 |
| `HUD` | 行动板顶部吸顶：学期名 + 行动点圆点 + 四轴迷你条。**精力是隐藏轴，永远不显示** |
| `TaskPanel` | 右上浮动角标「学姐的要求 n/m」，点开展开清单；打钩用 accent |
| `SpeakerTag` | senpai 用 accent-soft 底 accent 字；npc 用 line 底；system 无标签 |

## 5. 说话人视觉区分

| 角色 | 样式 |
|---|---|
| 学长（senpai） | 强调色标签「学长」，全产品唯一指导角色 |
| NPC（学姐/教务处…） | 灰标签，名字来自 `screen.npcName` |
| 系统旁白 | 无标签，直接正文 |

## 6. 动效白名单

只允许以下六种，均已定义为 Tailwind 动画：

1. `animate-fade-up`：屏幕/元素入场（0.35s，上移 8px 渐显）
2. `animate-num-pop`：数值跳动（速结结算用）
3. 进度条/四轴条 `transition-[width]`：数值增长
4. `active:scale-[0.97]`：按压反馈（Button 内置，含 hover 抬升 + 投影升档）
5. `animate-pop-in`：弹窗/引导气泡入场（0.3s，带轻微回弹）
6. `animate-breathe`：行动点可用态的呼吸微光（唯一允许的循环动画，面积极小）

禁止：视差、粒子、其余无限循环动画（打字机光标的 pulse 除外）。

## 7. 桌面端规则

- 1280×800 为设计基准；1024px 宽不破版即可（三栏网格不塌陷）。
- 弹层居中出现（`items-center`），遮罩 `bg-ink/30 backdrop-blur-[2px]`，面板 `shadow-pop animate-pop-in`；危险操作（重开/离开关卡）必须二次确认。
- hover 只做轻反馈（边框加深），不藏功能——所有交互点击即可完成。
- Home 与关卡页是两种页面气质：Home 是"桌面上的档案盘"（多面板并置），关卡页是"一页信纸"（单栏叙事）。不要互相污染。

## 7.1 Home 布局速查

```
┌ 顶栏：产品名 · 学期 ────────────── 玩家名·专业 · 账号 ┐
│ 导航 200px      │ 内容区 1fr        │ 状态栏 280px    │
│  本学期         │  （按导航切换）    │  行动点         │
│  文件夹         │  主线任务 Panel    │  属性面板(五轴) │
│  属性           │  选修行动 Panel    │  四年目标 flag  │
│  记录           │  结算按钮          │  已解锁能力     │
│  四年时间轴      │                   │                │
```
- Panel 组件：`rounded-2xl border-line bg-card p-5`，标题 15px semibold + 副标题 12px ink-soft。
- 主线卡片：序号圆徽（未解锁灰/可进橙/完成墨）+ tag 徽 + 描述一行截断。

## 8. 海报占位资产视觉要求（对应 docs/03 第 5 节）

- v1（首版）：主体色块几乎占满画面 → 玩家能一眼看出「主体太满」。
- v2（修正版）：上 1/3 是虚线框标注的「标题留白区」→ 与 v1 的差异肉眼可辨。
- 16:9：留白区移到左侧。
- 学长成品：带完成态文字排版（标题+社团名），与玩家版气质不同。
- 真图替换时保持同名同尺寸比例（3:4 = 600×800，16:9 = 1280×720）。
