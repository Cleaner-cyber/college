## 二、风格总纲（每条提示词开头都带这段，保证十张图是同一个世界）

> **通用前缀**：中国大学校园场景，写实摄影风格渲染，暖色调金色时段光线，画面干净细节丰富，无人物，无任何文字和水印，横版 16:9，分辨率 1920×1080。画面下方四分之一保持相对简洁（会被对话框覆盖），相机水平视角不倾斜、不广角畸变。

> **通用负面**：无人物、无文字、不过曝、不昏暗发灰、不倾斜、不鱼眼、不赛博霓虹、不冷色调。

统一原则（源自前期 10 款游戏 UI 调研 + 已定稿两张底图）：
1. **同一光线家族**：清晨金光 / 午后暖阳 / 黄昏晚霞 三档，全部是暖光——按剧情时段分配（见表），绝不出现冷白光/阴天；
2. **无人物**：VN 立绘和 UI 会叠在图上，场景本身必须是空景；
3. **下四分之一留白**：对话框+底部渐变会压在那里，桌面/地面在下方最合适，关键物件放中上；
4. **窗与灯是戏眼**：每个室内场景都要有一扇能看到校园的窗 + 一处暖光源（呼应宿舍图的台灯与窗）。

## 四、落地与验证

1. 生成后命名严格按「文件名」列，放入 `public/assets/`；刷新页面对应关卡的 VN 开场即替换（引擎 jpg 优先，占位 svg 自动兜底，无需改代码）；
2. bg-grad.jpg 是新增位，图就位后由开发侧在 settlement 内容里接一行场景配置（一分钟）；
3. 每张图生成后发一张截图核对两点：①下四分之一是否够简洁（对话框会压住）；②光线是否落在暖色家族内；
4. 立绘（学长 sprite）会叠在场景中央偏右，场景中部不要放过于抢眼的竖向物件。
