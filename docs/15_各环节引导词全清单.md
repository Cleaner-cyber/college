```

```

1. 这篇论文解决什么问题？之前的方法差在哪？
2. 方法的核心思路是什么？用我能听懂的方式讲；
3. 它的局限和未来方向是什么？
最后额外加一条：我一个大二本科生，能在这个方向上帮上什么忙？
要求：只依据论文内容回答，不要编造；凡是论文里没写、属于你推断的地方，明确标注出来。
```

**2. `q-email`（③ 按分寸起草套磁邮件）**
```
基于刚才的三问结论，帮我起草一封给王老师的套磁邮件。分寸要求，一条都不能破：
1. 正文 150 字以内；
2. 称呼就是「王老师」，不要「亲爱的」「尊敬的」那一套；
3. 第一句自报家门：学院、年级、姓名；
4. 中间用一句话证明我真的读过他的论文（引用三问里的结论）；
5. 结尾只提一个请求：约 15 分钟当面请教，不多要；
6. 说明随信附上成绩单。
不要吹捧，不要卖惨。写完之后，逐句给我讲清楚你为什么这样写。
```

**3. `q-send`（④ 检查完毕，发送）**
```

```

## 大二上 ·《专业课救命笔记》（notes）

```

4. **课后待办**：老师布置的作业和提到的预习内容。
约束：录音里听不清或不确定的地方，**直接标注出来，不要靠猜补全**——这是复习材料，编错一个定义比空着更糟。

**4. `q-exam`（把笔记喂回去，让它出卷考我）**
