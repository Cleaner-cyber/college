# 01 · 产品定义书

> v1.1 · 2026-07 · 本文档回答"做什么、为什么"；怎么做见 02/03。
> v1.1 变更：明确双目标；桌面端；前后端分离（Supabase）+ 登录注册；教学关改为主线必修；Home 主界面。

## 一句话
一个大学四年模拟器，教 AI 小白在真实校园场景里学会用 AI——里面掉落的东西是真的。

## 双目标（产品存在的理由，缺一不可）
1. **大学规划**：让准大一新生把大学四年先"过一遍"——分配时间、做取舍、看见选择的后果，协助他们规划真实的大学四年。
2. **AI 教学**：目标用户是零计算机/AI 基础的小白。用交互式引导，在真实校园场景（海报、PPT、长文档、面试…）里教会他们用 AI 提效。
   **推论：所有教学型/交付型关卡是主线必修，每个玩家必须经历，不允许被行动点分配"绕过"。**

## 核心论点
大学四年的本质，是用有限的时间换成果。AI 改变的是汇率。

## 目标用户
准大一新生（AI 小白），桌面端浏览器。全程被引导，几乎不打字。
正式投入使用：需注册登录（邮箱+密码），进度存云端，换设备可续玩。

## 双层结构
- **决策层**：学期卡 → 行动板（行动点分配）→ 结算。负责"人生规划"价值。
- **执行层**：教学关卡，跑五环节（接活→喂料→生成→返工→交付）。负责"学会 AI"价值。
- 两层仅通过两种货币耦合：**行动点**（时间）与**档案**（成果）。

## 核心机制（全部已拍板；v1.1 修订行动点规则）
| 机制 | 规则 |
|---|---|
| 主线必修 | 教学/交付型关卡：**不耗行动点、顺序解锁、全部完成才能结算学期**。这是"AI 教学"目标的机制保障 |
| 行动点 | 每学期 3 点，**只用于选修行动**；已学对应 AI 能力的选修行动打折（折扣=复利）。结算时剩余点自动转化为休息（精力+1/点） |
| 数值 | 四轴：学术/作品/表达/现金 + 精力（HUD 隐藏，属性面板可见）。选择只买入场券，数值由关卡表现给（验收清单打钩数） |
| 「什么都不做」 | 永远在行动板上，给精力 +2，零羞辱 |
| 学长系统 | 唯一指导角色。求助按钮 = [问学长]，跳过深度关卡，产物入库但标记 borrowed |
| 开局 flag | 点选：年薪区间/城市/工作类型/下班时间。结局时原样放回对照 |
| 结局 | flag 对照 + 四轴形状 → 身份卡（有好坏；差结局指向自己的选择，不指向社会位置，不用真实职业当坏结局）+ "你自己做了 N/M 件" |
| 判定 | A 绝对阈值起步；每个玩家的四轴与结局数据从第一天就落存档，为将来切相对分布（稀有度）留管道 |

## 训练型 vs 交付型（已拍板）
- **训练型**：教流程，内容全预设（预制图/预写文本的演出）。绝大多数关卡属于此类。
- **交付型**：产出带用户名字、游戏外仍有用的真东西。全产品仅四件：
  1. 专业卡片（预生成库，按专业取，可截图）
  2. 简历（档案条目自动填充模板，零输入零调用）
  3. 个人主页（**全产品唯一真实 AI 运行时调用**，产出真链接）——不在 demo 范围
  4. 结局卡（档案数据插值，分享引擎）
- 全四年用户打字仅 3 次：姓名、社团名（可默认）、一句话自介（#15 用）。

## 当前范围（v1.2：覆盖第一学年）
```
注册/登录 → 序章(#0，建档) → Home 主界面
  ├─ 大一上：主线 选课关(#1) → 海报关(#3)；选修速结×4（行动点 3）→ 学期结算
  ├─ 大一下：主线 PPT关(#5，结构化生成)；选修速结×4（行动点重发 3）→ 学期结算
  └─ 第一学年结束态（可复看结局卡/重开）
```
- **游戏结构**：Home 主界面（hub）与关卡页面分离。Home 上可随时查看：本学期任务、文件夹（档案）、属性面板（五轴+行动点+目标 flag+已解锁能力）、行动记录、四年时间轴。
- **前后端分离**：前端静态站 + Supabase（登录注册、云存档、RLS）。未配置时降级本地试玩模式（开发/演示用）。
- 关卡内所有"AI 生成"仍为预设内容演出（零真实 AI 调用）。
- 明确不做：#2 面试、#4 笔记、付费、分享图合成、真实生图、PDF 解析、手机端适配。

## 验收标准（v1.1）
1. 新用户注册到学期结算 ≤ 15 分钟，无需指导
2. 桌面端（1280px 基准）体验完整，1024px 不破版
3. 云存档：换浏览器登录同一账号可续玩；中断续玩粒度=关卡完成
4. 主线必修不可绕过：不完成选课+海报无法结算学期
5. 内测 10 人中 ≥3 人主动问"后面的什么时候能玩"
