# 06 · 内容运营手册

> v1.0 · 补充文档，写给内容负责人：不改代码的前提下，能改什么、怎么改、改完怎么验证。

## 0. 原则

所有玩家看到的中文都在 `/content` 下的 JSON 里。**润色台词 = 改 JSON = 不需要开发介入**；改完跑一次 `npm run build`（或让开发跑）确认 JSON 没写坏即可。

## 1. 改台词/按钮文案

| 想改什么 | 文件 | 位置 |
|---|---|---|
| 序章台词、flag 选项 | `content/levels/prologue.json` | `screens[].text` / `choices[].label` |
| 选课关：AI 对话的提示词与回答 | `content/levels/course-select.json` | `copy.q1/a1/q2/a2/q3/a3`（回答支持 Markdown：`###` 标题、`\|` 表格、`-` 列表、`**加粗**`）；文件卡名称在 `copy.file-*`；学长旁白在 `copy.senpai-*` |
| 海报关台词、提示词文案 | `content/levels/poster.json` | `screens[].text` / `copy.s7-*` / `copy.s10-full-prompt` |
| 结算判词 | `content/levels/settlement.json` | `copy.verdict-*`（六条：四轴各一 + 休整型 + 均衡型） |
| 速结行动一句话与学长点评 | `content/quick-actions/y1s1.json` | `resultText` / `senpaiComment` |
| 主线任务卡标题/描述/锁文案 | `content/board/y1s1.json` | `mainline[].label/tag/desc` / `mainlineLockText` / `electivesLockText` |
| 登录注册文案（含报错） | `content/ui/ui.json` | `auth.*` |
| Home 界面文案（导航/面板/时间轴/结束态） | `content/ui/ui.json` | `home.*` |
| 行动记录的句式模板 | `content/ui/ui.json` | `log-tmpl.*`（保留 `{label}` 等变量） |
| 能力名称 | `content/ui/ui.json` | `abilities.*` |
| 按钮/清单等其余全局文案 | `content/ui/ui.json` | 对应键 |

写法约定：

- 台词换行用 `\n`；插值变量 `{playerName}` `{majorName}` `{clubName}` 原样保留。
- 按钮文案键：`next-屏id`（如 `next-S5` 是 S5 屏的下一步按钮）；输入屏确认键 `confirm-屏id`。
- 假加载轮播旁批：`screens[].effects.fakeLoading.tips` 数组，每条 ≤ 18 字最佳；`ms` 是时长（毫秒），可调。

## 2. 专业库（content/majors/majors.json）

- 当前收录 30 个热门专业 + 1 个兜底 `generic`（**不要删**，搜索无结果时自动使用）。
- 新增专业：复制一个条目改内容。`id` 用小写英文短横线；`aliases` 放考生常搜的简称（如「计科」「CS」）。
- 卡片五栏字数建议：主干课 ≤6 门；毕业去向 ≤4 条；`secret`（没人告诉你的一件事）是传播点，一句话、有信息差、不贩卖焦虑。

## 3. 替换海报真图

1. 真图按下表命名，直接放进 `public/assets/` **覆盖同名 SVG 改为同名图片时需保留扩展名一致**——最省事的做法：真图导出为同名 `.svg` 封装（或告知开发改 `poster.json` 里 `presetAssets` 的路径扩展名，11 处，一分钟的事）。
2. 尺寸：3:4 = 600×800 起，16:9 = 1280×720 起。

| 文件名 | 内容要求 |
|---|---|
| `poster-{jj\|sh\|sy}-34-v1` | 极简/手绘/摄影 × 首版：**主体偏满**（这是教学点，不是瑕疵） |
| `poster-{style}-34-v2` | 修正版：上 1/3 留白明显，与 v1 差异肉眼可辨 |
| `poster-{style}-169` | 16:9 版，留白在左侧 |
| `poster-senpai-34` / `-169` | 学长成品，含完成态文字排版（走[问学长]时展示） |
| `senpai.svg` | **学长头像**（当前为手绘线稿占位）。自己手绘后导出同名 SVG/正方形图替换即可，全站对话头像自动更新 |

注意：v1 图上不要压社团名文字——社团名是游戏里的文字层叠加的（玩家输入什么显示什么）。

## 4. 改完后的验收清单（对照 docs/01 Demo 验收标准）

- [ ] `npm run build` 零报错（JSON 语法坏了这里会挂）
- [ ] 桌面端（1280px）走完整流程 ≤ 15 分钟：注册/登录 → 序章 → 主线×2 → 速结 → 结算
- [ ] 主线必修绕不过：不做完选课+海报，「结束这学期」不可点
- [ ] 序章选一个小众词（如「敦煌学」）→ 出兜底通用卡，文案不尴尬
- [ ] 海报关走一次 [问学长] → 文件夹出现「借来的」标签，结局卡「自己做了 N/M 件」数字变化
- [ ] 中途关掉浏览器再打开（或换设备登录同一账号）→ 从 Home 继续
- [ ] 全程除 Supabase 外无网络请求（开发者工具 Network 检查）

## 5. 文案基调备忘（从 docs/01/03 提炼）

- 学长：过来人，不端着，不客服腔；可以自嘲（「我当年没读」），不说教。
- 差结局/低产出不羞辱：「什么都不做」的判词也要体面（见 `verdict-rest`）。
- flag 屏基调：认真但不施压，脚注「随便选。反正你会忘。」是定调句，慎改。
- 教学口诀是资产，改前过一遍负责人：「别读长文件，喂长文件」「尺寸是参数，构图才需要你说话」「改提示词，不是重新许愿」。
