# 10 · 专业知识库（knowledge/majors）使用指南

> v1.0 · 2026-07 · 来源：用户提供的《1002 中国大学的专业规划》知识库。
> 位置：`knowledge/majors/`（14 门类 / 92 专业类 / 790 专业文档，22MB）。**仅供内容设计取材，不进前端打包。**
> 本文由 5 个并行代理逐门类通读后汇总。机器索引：`knowledge/majors/index.json`；游戏内 37 个专业的文档映射：`knowledge/majors/mapping.json`（全部命中）。

## 一、内容模板（全库高度统一，适合结构化抽取）

绝大多数专业文档为第一人称"学长口吻"，固定 9-10 个 H2 小节 + 文末 AUTO_NAV 导航（Obsidian 双链，含跨库引用）：

| 知识库小节 | 可直接转成的游戏素材 |
|---|---|
| 专业定位 / 适合人群 | 序章专业卡片、专业选择引导 |
| 四年路线图（逐年逐学期） | **学期事件卡时间轴**、行动窗口（semesterMin/Max）校准 |
| 核心课程 / 能力栈（硬技能/软技能/证书） | 行动板证书行动、成就系统、能力解锁 |
| 升学就业（含薪资带/考研分数线/考公岗位） | **路线分叉事件、结局判定与身份卡文案（P2）** |
| 避坑点（坑一~坑五，各配反例故事） | **专业专属负面事件/时机错配卡**（最高价值素材） |
| 与 AI/新产业结合 | AI 教学主线与专业的连接点、新兴职业结局 |

两套模板变体：A「标准九段」（主流）；B「过来人复盘体」（金融学/法学/学前教育等，小节名不同但内核一致）。文学类一致性最差，历史学类最统一。

## 三、游戏 9 大类映射总表（5 个代理独立结论一致）

主体映射：哲学/文学/历史 → hum；经济/管理主体 → biz；法学类+公安 → law；教育/体育 → edu；理学 → sci；工学主体 → eng（计算机类及 AI/网安/机器人 → cs）；医学主体 → med；艺术 → design；农学 → sci 为底。

**约 30 个交叉专业建议用「主类 + 次标签」表达**（无需扩 9 大类枚举），典型：逻辑学 hum+cs、金融工程 biz+sci、知识产权 law+eng、计算语言学 hum+cs、生物医学工程 eng+med、数字媒体技术 cs+design、运动康复 edu+med、艺术治疗 design+med、农林经济 sci+biz。
→ 落地方式：Major.category 保持主类，未来在 majors.json 加可选 `subCategory` 供行动板扩展过滤（P2+ 候选，暂未实现）。

## 四、已接入与后续接入点

已接入：
- `knowledge/majors/index.json`：门类→专业类→专业 索引（脚本生成）
- `knowledge/majors/mapping.json`：游戏 37 个专业 → 知识库文档路径（37/37 命中）
- **全量专业目录（v2.5，scripts/gen-majors.py）**：
  - `content/majors/catalog.json`：700+ 可选专业（id=专业名，门类/专业类/游戏大类），取代手写 majors.json；旧 37 个短 id 作 aliases 兜底旧档
  - `public/assets/majors/<专业名>.json`：单专业详情（速览卡 5 字段启发式抽取 + 全部小节原文），序章/文件夹按需 fetch（同源静态资源，不进打包体积）
  - 序章专业选择改为 搜索 + 门类→专业类→专业 分级浏览；专业卡片与「查看详细专业情况」全文均出自知识库
  - 知识库更新后重跑 `python3 scripts/gen-majors.py` 即可同步

后续取材路径（对应 docs/08 分期）:
1. **专业专属事件包**（P1 延伸）：从各专业「避坑点」抽事件卡——每个行动板大类先做 3-5 张（法考挤兑、口腔填报坑、强弱电分流、作品集焦虑…）
2. **P2 结局与身份卡**：从「升学就业」节抽路线分叉与结局文案（薪资带/考编/读研分叉均有现成数字与话术）
3. **成就系统**：从「能力栈-证书」节抽证书/竞赛成就清单（每大类 5-8 个）
4. **序章专业卡片增强**：mapping.json 直达对应文档的「专业定位/适合人群」，可替换现 majors.json 卡片文案
5. **学长台词库**：全库第一人称学长口吻与游戏「学长」角色天然契合，可直接改写引用

## 五、数据质量注意（引用前必读）

- **AI 去味残留**：偶有病句与截断句（「总之保研到了清华」「我一」）；库顶层附《AI去味处理规范.md》，摘录进游戏前需人工顺一遍
- **重复文件**：国际税收/保险学/公共艺术等在两个专业类下重复出现，以 index.json 首见为准
- **层级错级**：个别文件 H2/H3 错用（哲学.md、学前教育.md），解析时以小节名而非层级为锚
- **薪资/分数线数字**：文档标注为 2026 行情，未经本项目核验——游戏中作叙事参考可，作"事实陈述"需谨慎
- 军事学类为空目录；交叉学科桩文件见第二节表格注
