## A. 序章 prologue

### 流程
```
S1 开场 → S2 输入姓名 → S3 选专业 → S4 立flag(×4屏或一屏四组) → S5 绑定学长系统
→ S6 专业卡片揭示 → S7 文件夹引入 → 进入行动板
```

### 逐屏
| 屏 | type | 内容 | 交互/映射 |
|---|---|---|---|
| S1 | dialogue(system) | 「2026年8月。你的录取通知书到了。」 | [拆开] → S2 |
| S2 | input | 「通知书上的名字是——」 | inputKey=playerName，≤8字 → S3 |
| S3 | choice(搜索选择器) | 「录取专业：」 | 从 majors.json 搜索选择，写入 majorId → S4。无结果→兜底通用卡 |
| S4 | choice×4 | 「入学之前，先回答一个没人会问你的问题：四年后，你想要什么样的生活？」四组按钮：年薪区间 / 城市 / 工作类型 / 下班时间 | 全点选，写入 flag → S5。文案基调：认真但不施压，最后一行小字「随便选。反正你会忘。」 |
| S5 | dialogue(senpai) | 「叮——学长系统绑定成功。」「别紧张，我不是客服。我是四年前坐在你这个位置的人。」 | [你是谁？] → S6 |
| S6 | reveal | 专业卡片：从 majors.json 渲染 {majorName} 的五栏卡片 | effects: typewriter + fakeLoading(1500ms, tips:["学长翻了翻他的旧笔记…"])。底部小字「第 1 件 · 已放进文件夹」→ 档案入库 |
| S7 | dialogue(senpai) | 「我毕业时留下了一个文件夹，里面是我四年做过的每一件东西。」「现在它是你的了。往里装点你自己的吧。」 | [开始大一] → onComplete |

### 结果
- deltas: 无；abilityUnlocks: 无
- archiveItems: [{ id:'major-card', levelId:'prologue', title:'我的专业卡片', resumeLine:'', borrowed:false, assetRef:'major-card' }]

## B. 大一上 · 行动板 y1s1

### 布局（引擎实现，非关卡）
- 顶部：`大一上 · 9月` + 行动点 ●●● + 四轴迷你条
- 必修置顶（免费，不耗点）：**选课周**（未完成时锁住下方行动板，文案「先把课选了」）
- 行动列表（完成选课后解锁）：

| 行动 id | label | 耗点 | 折扣 | deltas | 类型 |
|---|---|---|---|---|---|
| poster | 给社团做招新海报 | 2 | image-gen→1 | 由关卡结果定 | 深度关卡 |
| election | 竞选班委 | 1 | — | expression+2, energy-1 | 速结 |
| gpa | 泡图书馆刷绩点 | 1 | — | academic+2, energy-1 | 速结 |
| tutor | 接一份家教 | 1 | — | cash+2, energy-1 | 速结 |
| rest | 什么都不做 | 0 | — | energy+2 | 速结 |
- 行动点用尽 → [结束这学期] 按钮亮起 → 结算
- 速结演出：点击 → 0.8s 数值跳动 + resultText 一句话 + 学长点评（可空）。示例 rest 的 resultText：「你睡了很多觉，看了两部电影。没有任何产出。挺好的。」

## C. 选课关 course-select（必修 · 免费 · 教学：投喂长文档）

### 流程
```
S1 情境 → S2 拖入PDF → S3 假解析 → S4 三条结论逐条揭示 → S5 追问×2 → S6 交付避坑课表 → 完成
```

### 逐屏
| 屏 | type | 内容 | 交互/映射 |
|---|---|---|---|
| S1 | dialogue(npc:教务处) | 「新生请于本周内完成选课。附件：《2026级培养方案》.pdf（87页）」学长旁批：「我当年没读。大二才发现有门课必须大一修，卡了我保研资格。」「这次你不用读。你只需要学会一个动作。」 | [什么动作？] → S2 |
| S2 | workbench | 一个对话框 + 一份 PDF 图标。引导手势：把 PDF 拖进对话框（移动端为点按「拖入」） | 拖入动画 → S3 |
| S3 | reveal | effects.fakeLoading(2500ms, tips:["87页，AI 读它只要几秒","你要学的不是读文件，是喂文件"]) | 自动 → S4 |
| S4 | reveal | 三条结论逐条打字机：①必修里有一门《XX基础》只在大一开，错过等大三重修 ②《高等数学A》是全院挂科率最高的课，占学分最重 ③想保研的话，前三学期绩点占评定的70% | [继续] → S5 |
| S5 | choice | 追问按钮（选一个看回答，另一个仍可点）：[哪些课能大二再修？] [我想转专业要注意什么？] 回答均预写 | 各回一段 → S6 |
| S6 | deliver | 「大一避坑课表」卡片 + 学长：「这一关我不收你行动点。因为学会了它，你后面每一关都省时间。」「记住这个动作：**别读长文件，喂长文件。**」 | onComplete |

### 结果
- deltas: 无；abilityUnlocks: ['doc-feeding']
- archiveItems: [{ id:'course-map', levelId:'course-select', title:'大一避坑课表', resumeLine:'', borrowed:false }]
- 完成后行动板解锁，且带折扣的行动显示 ⚡ 角标

## D. 海报关 poster（选修 · 深度 · 教学：生图+迭代 · 全预设演出）

### 流程
```
S1 学姐派活 → S2 任务面板 → S3 喂料(社团名/风格) → S4 假生成 → S5 首版出图+部分打钩
→ S6 学姐驳回 → S7 修改选择(提示词可视化) → S8 二版出图 → S9 16:9版 → S10 交付
任意时刻可点 [问学长] → ESC 屏 → 直接入库学长成品(borrowed)
```

### 验收清单 checklist
| id | label |
|---|---|
| ck-ratio | 3:4 竖版 |
| ck-space | 标题区留白在上方 |
| ck-name | 出现社团名 |
| ck-169 | 追加 16:9 版 |

### 逐屏
| 屏 | type | 内容 | 交互/映射 |
|---|---|---|---|
| S1 | dialogue(npc:学姐) | 「周五要用招新海报。3:4，贴宣传栏。标题那块给我留空，字我们自己压。要有社团名。」 | [接下] → S2 |
| S2 | dialogue(senpai) | 任务面板亮起(4项)。「先别急着跟AI说『好看一点』。她要的三件事，就是你提示词的三句话。」 | [开始] → S3 |
| S3 | workbench | ①社团名 input(inputKey=clubName，默认值「星野动漫社」可直接用) ②风格三选一缩略图(极简/手绘/摄影)→setVar style ③尺寸按钮[3:4][16:9][1:1]，选3:4→checkItem ck-ratio。旁注小字：「尺寸是参数，不用写进提示词——构图才需要你说话」 | [生成] → S4 |
| S4 | reveal | fakeLoading(3000ms, tips:["真实出图大概要20秒，习惯它","提示词已带上：上三分之一留白，主体在下"]) | → S5 |
| S5 | reveal | showAsset:"poster-{style}-34-v1"，社团名以文字层叠加(→checkItem ck-name)。学长：「注意，它没完全听你的——主体有点满。真实的AI就这样。所以才有下一步。」 | [交给学姐] → S6 |
| S6 | dialogue(npc:学姐) | 「主体太满了，标题没地方放。另外公众号头图还要一版16:9的。」 | [改] → S7 |
| S7 | choice | 三个修改按钮：[主体往下压] [背景压暗] [保持构图再抽一次]。**右侧同步展示提示词变化**：选中项以高亮文字追加到原提示词尾部（预写文案） | 任选→setVar revision + checkItem ck-space → S8 |
| S8 | reveal | fakeLoading(2000ms) → showAsset:"poster-{style}-34-v2" | [出16:9版] → S9 |
| S9 | reveal | 「同一句提示词，只换一个参数。」→ showAsset:"poster-{style}-169"，checkItem ck-169 | [交付] → S10 |
| S10 | deliver | 双图并排入库动画，清单4/4。学姐：「行，比上届强。」学长：「当年这张我改了三遍。你比我快。」+ 解锁按钮[看学长当年的完整提示词]（展开预写提示词全文） | onComplete |
| ESC | deliver | 学长：「卡住了？拿我那版去交吧。但答应我，下学期自己做一张。」入库学长成品 | onEscape，borrowed:true |

### 结果
- deltas: 按清单：4/4→portfolio+2；2~3→portfolio+1；ESC→portfolio+1
- abilityUnlocks: ['image-gen']
- archiveItems: [{ id:'poster-y1', levelId:'poster', title:'社团招新海报 · 双版本', resumeLine:'独立完成社团宣传物料设计（3:4/16:9双版本）', borrowed:视路径 }]

## E. 学期结算 settlement

### 流程
```
S1 学期小结(数值动画) → S2 档案一览 → S3 简易结局卡 → S4 结尾钩子
```

| 屏 | 内容 |
|---|---|
| S1 | 「大一上 · 结束」四轴增长动画 + 本学期行动回放列表（每行一句 resultText） |
| S2 | 文件夹视图：已入库条目（含 borrowed 标记显示为「借来的」小标签） |
| S3 | 简易结局卡：①顶部原样放回开局 flag「入学前，你说你想要——」②四轴形状图 ③一句判词（预写规则：取最高轴，各写一句；全低且精力高→「休整型开局」判词，同样体面）④「这学期 N 件作品里，你自己做了 M 件」 |
| S4 | 学长：「这才是第一个学期。」灰显的后续学期时间轴（大一下…毕业）+「Demo 到这里。想看后面的，告诉学长。」 |
