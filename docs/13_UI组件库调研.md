# 13 · UI 组件库调研与落地（React Bits / Aceternity UI / Uiverse.io）

> v1.0 · 2026-08 · 结论先行：**三家都只当「机制库」用，不当「主题库」用**——
> 取其动效工艺，颜色一律换成我们的暖色 token；与「文件夹/档案/信纸」气质相反的（霓虹/极光/故障风）永不引入。
> 调研方式：两个调研员分别克隆/镜像读源码（营销站被代理封锁，全部走 GitHub），逐组件查依赖与许可证。

## 一、许可证与分发结论

| 库 | 许可证 | 对我们的含义 |
|---|---|---|
| React Bits（`DavidHDev/react-bits`，165 组件） | **MIT + Commons Clause** | 复制进游戏（含商用）明确允许；只禁止把组件本身转卖/再分发为组件库 |

## 二、硬约束（筛选尺子）

1. **零运行时网络请求**：Aceternity 的 Link Preview 运行时调 microlink 截图 API——硬性排除；其余组件均本地。
2. **包体预算**：当前 JS 644KB。framer-motion(motion) ~50KB gz 是唯一可考虑的引擎；
   **three.js(~160KB)/ogl/gsap/tsparticles/matter-js 一律不引**——React Bits 全部 52 个 Backgrounds 和
   Aceternity 的 Sparkles/Canvas Reveal 等因此整类出局。
3. **动效纪律**（docs/04 白名单精神的延伸）：只允许 ①hover 触发的一次性效果 ②一次性入场
   ③状态变化的一次性反馈 ④加载指示（无限循环动画唯一的正当场合）；一律带 `prefers-reduced-motion` 降级。
   两家 React 库对 reduced-motion 几乎零处理（React Bits 165 个里只有 22 个自查，Uiverse 3802 个里只有 7 个）——**必须自己补**。
4. **中文适配**：按词拆分的文本动效（BlurText words 模式、TextGenerateEffect）要改 `Array.from`；
   变量字体类（VariableProximity）无 CJK 变量字体，排除。
5. **性能模式**：hover 卡逐帧 setState 是 React Bits 已知坑（SpotlightCard），网格卡片一律改「ref 写 CSS 变量」。

## 四、第二梯队（机制已验证可行，有明确落点时再做）

- **Aceternity Compare**（before/after 滑块，motion）：教学关「AI 改前 vs 改后」对比——两库中教学价值最高的组件；
  引入它是唯一值得为之引入 motion 的场合。
- **Aceternity Multi Step Loader**（分步假加载清单）：升级假生成演出（"正在分析文档…提取要点…生成大纲…"）——
  可零依赖重写。
- **React Bits Folder**（零依赖，纸页扇出的文件夹）：字面意义上的「档案」隐喻，重着色后放文件夹空态/入口。
- **Aceternity Highlight**（记号笔划重点）：学长对话里的关键术语强调——可 CSS 渐变零依赖重写。
- **Uiverse 铅笔画线加载器**（`Shoh2008_hot-hound-11`）：「学长正在写…」场景。
- **Uiverse 字压按钮**（`Afacanc38_polite-chipmunk-64` letterpress）：暂缓——静息态需要浮雕底，与现在的扁平玻璃按钮语言冲突。

## 五、永不引入（与基调/约束冲突）

- 一切 three/ogl/gsap/tsparticles/matter-js 依赖组件（单个特效即吹爆包体预算）
- 两家全部背景特效：Aurora/极光、Meteors/流星、星空、Hyperspeed、Plasma、Beams、Boxes、Vortex——明令禁止的赛博朋克系，且我们有实景底图
- 故障/加密风：GlitchText、LetterGlitch、FaultyTerminal、Evervault、DecryptedText（教学关之外）
- 全息彩虹卡（ProfileCard、GlareCard 彩虹箔）、光标玩具全家（BlobCursor/SplashCursor/ImageTrail…）
- **Aceternity Link Preview**：运行时调外部 API，违反网络白名单，硬性排除
- Uiverse 里 tag 含 neon/glow/gradient/cyberpunk 的长尾（如 918 行的霓虹输入框）；依赖 Font Awesome 的 6 个文件

## 六、翻译 Uiverse 元素到 React 的检查单

1. `display:none` 藏原生 input 的（223/533 个选择类元素都这么干）→ 改 sr-only + `:focus-visible` 环，否则键盘/读屏全废
2. 硬编码 id（`id="uv-checkbox"`）→ 参数化，列表渲染会撞
3. ~94% 硬编码 px → 按落点重新定尺
4. 无限动画 → 确认是否加载场合；不是就改一次性触发
5. 颜色全部换 token，别信原色
